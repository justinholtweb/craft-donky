# Plugin Store promo images

Marketing images for the Donky listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-donky](https://justinholt.com/plugins/craft-donky).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `donky-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Every slide is pure CSS and type — there are no control-panel screenshots yet. When there is a
live install to shoot, screenshot slides can be added alongside these without redoing anything:
copy the `.cpcard` pattern from `craft-abacus/promos/slides.html`.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#2F6B52`, sand `#E7CFAE`, Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the donkey with the **tile stripped**, generated from `../src/icon-mask.svg`.
  The app icon's rounded tile reads as a hard-edged box at watermark scale, which is why the tile
  is removed rather than the whole icon being faded further.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## A trap worth keeping

**`.points li` is deliberately not a flex row.** A flex row turns every inline
`<span class="mono">` or `<em>` inside a bullet into its own flex item, and the sentence renders
as three ragged columns. The tick is positioned out of flow instead, so inline copy stays inline.
